# Asset licensing

The files in this folder are bundled into the public GitHub Pages build. Before
publishing, make sure every asset is either original work or licensed for public
distribution.

- `cake-illustration.webp` and `hydrangea-carnation-frame.webp` — project
  illustrations. Confirm the illustrator's terms before redistributing.
- `metal.mp3` — background track. Replace it with a recording you have the
  rights to publish; do not ship a commercial recording without a license.
- Fonts live in `src/app/fonts/`. Keep their license files with the project if
  they are redistributed.
